## Keyword Usage Guidelines

### Title Tags (50-60 characters)
- Primary keyword at the beginning
- Include brand name (aqro)
- Make it compelling and specific

### Meta Descriptions (150-160 characters)
- Include 2-3 primary keywords naturally
- Clear value proposition
- Call to action (e.g., "Get custom development")

### Headers (H1, H2, H3)
- H1: Primary service keyword
- H2: Technology/domain keywords
- H3: Specific features/benefits

### Content Body
- Keyword density: 1-2%
- Natural placement
- Use variations and synonyms
- Include technology stack terms

### URL Structure
- `/services` - project development keywords
- `/pricing` - project pricing keywords
- `/showcase` - portfolio keywords
- `/process` - development workflow keywords
